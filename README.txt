MOLAR & MINT DENTAL STUDIO — STATIC DEMO WEBSITE

Start:
1. Extract the ZIP.
2. Open the molar-mint-dental folder in VS Code.
3. Install/use Live Server extension if needed.
4. Right-click index.html and choose Open with Live Server.

Pages:
index.html, services.html, clinics.html, clinic-details.html, booking.html,
confirmation.html, how-it-works.html, about.html, contact.html
Shared assets: styles.css and app.js

Features:
- Responsive layouts for desktop, tablet and mobile
- Dental services cards with relevant images and sample prices
- Searchable sample clinic list and clinic detail page
- Appointment flow with date and 20-minute slot selection
- Browser-local slot blocking after demo confirmation
- Demo OTP 123456 (no real SMS is sent)
- Animated hero zoom and Play/Pause dental-tour guide

IMPORTANT:
This is a static frontend demo. Clinic names, fees, ratings, locations, schedules and availability are sample data. Booking confirmation is not sent to any real clinic. No backend or SMS integration is included. Images are loaded from Unsplash URLs and require an internet connection. Verify image usage and replace with licensed/approved assets before production.
